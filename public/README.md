# THÉSOROS public assets

## Hero background images

Add these files here so the landing hero is responsive:

| Breakpoint | Filenames (first match wins) |
|------------|------------------------------|
| **Mobile** (&lt; 768px) | `background-mobile.webp`, `background-mobile.jpg`, `background-mobile.jpeg`, `background-mobile.png` |
| **Tablet** (768–1023px) | `background-tablet.webp`, `background-tablet.jpg`, `background-tablet.jpeg`, `background-tablet.png` |
| **Desktop** (≥ 1024px) | `background.webp`, `background.jpg`, `Background.jpg`, `background.jpeg`, `background.png` |

### Recommendations
- Desktop: ~1920×1080 or larger, cinematic luxury / wealth imagery
- Tablet: ~1200×900
- Mobile: ~750×1334 (portrait-friendly crop)
- Prefer WebP when possible; JPEG is fine
- Only the **hero** uses these images. Other sections stay near-black by design.

If files are missing, the page still renders with a dark luxury gradient.
